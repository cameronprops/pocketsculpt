# Pocket Sculpt Android 0.1

First native Android OpenGL ES 2.0 rendering test. A shaded 3D creature made from overlapping spheres and tapered bone tubes. One-finger orbit, two-finger zoom. This is **not** yet an editable skeleton, continuous mesh, or printable geometry.

## Download APK
Open the repository **Actions** tab, choose the latest successful **Android APK** run, then download **PocketSculpt-Android-debug** under Artifacts. Unzip and install app-debug.apk on Android.

## Local build
Open the android directory in Android Studio (JDK 17, Android SDK 35), let Gradle sync, and build the debug APK.

This native app is separate from the earlier HTML prototype at the repository root.
