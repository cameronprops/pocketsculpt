# Pocket Sculpt Web v0.6.1

Touch-first creature sculpting prototype. This web branch is separate from the Android app on main.

## Run

```sh
cd web
npm install
npm run build
npm run dev
```

The browser application supports skeleton joints, branching, implicit mesh generation, touch orbit and zoom, local autosave, JSON project files, undo, and OBJ export. This is a development build, not yet a full sculpting brush engine. GitHub Actions verifies the TypeScript and Vite build.
